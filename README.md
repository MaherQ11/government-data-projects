# Government Data Projects

Case studies from my work as a Data Analyst Trainee at the **Holy Makkah Municipality**.

The data behind these projects is internal, so each page describes the problem, the approach and the results — no project names, budgets or personal data.

| Project | What it solved | Result |
|---------|---------------|--------|
| [Project Portfolio Dashboard](pmo-project-portfolio.md) | Out-of-date project data and wrong reports after the PMO's project platform lost support | ~1,000 projects cleaned and moved to Power BI + SharePoint, used by the whole PMO department |
| [Project Matching Tool](project-matching-tool.md) | Two project lists that write the same project in different ways | 60 of 61 manual matches confirmed, plus 6 matches the team had missed |
| [Legal Case Automation](legal-case-automation.md) | Court cases entered by hand on a government legal platform, 4–5 min each | ~30 sec per case on the live platform; 542 of 544 cases matched to their consultant |
| [Feasibility Study Platform](feasibility-study-platform.md) *(in progress)* | Feasibility studies written by hand; the strategic section alone took ~1 week | Strategic section approved by engineers, now under 1 day |

**Skills:** Data cleaning · Data matching · Power BI · Excel · SharePoint · Python (pandas, Streamlit) · JavaScript browser automation · Cloudflare Workers
